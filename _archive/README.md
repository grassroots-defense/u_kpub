# Grassroots Defense ver.4.5 · 2.5D

スペースインベーダー風 1画面シューティング。

- 山：3層（ぼかし filter なし）・背景キャッシュ
- 地面：透視台形（静的部分キャッシュ）
- 川：山の谷・大地のくぼみに彫り込む地形一体型
- 毎フレームの重い計算を削減して FPS 安定化

## 起動

1. オープニング `GGDOP.jpg` ＋ テキスト
2. タイトル：待機 BGM「タッタカ、タッタカ」＋ 難易度
3. 防衛開始 → SE「タタタン♪」（画面表示なし）→ ゲーム開始

## 難易度

| キー | 難易度 | 攻撃総量 |
|------|--------|----------|
| 1 | イージー | −30% |
| 2 | ノーマル | 基準 |
| 3 | ハード | ＋10% |
| 4 | スーパーハード | ＋50% ＋ 謎攻撃量増加 |

## アイテム（現行）

- 🌱種 / 📘知恵 … 通常敵などから
- ⚡連射・≡三連 … 上を横切る敵を倒したときだけドロップ。効果 約6〜7秒
- 🛡シールド … 耐久制（取得で耐久2）。被弾で減り、薄く点滅

## 都市化

- 📘知恵の実で遠景の都市が 徐々に発展（約20個で Max）
- 一度上がった都市化は 戻らない（ラン中永続。敗北・リセットで初期化）
- HUD に 都市0〜3 を表示

## 視界

- 光化学スモッグが多いと画面が 霞む
- 巨大スモッグは濃い霧（まだらから広がる）

## 稲妻

- ピカっと光る ＋ 地上の黄色い線
- 当たり判定あり（線・縦ボルトに触れると被弾）
- SE：ピカゴロゴロ ＋ バリバリバリバリ

## 3点射撃取得演出

取った瞬間、自機の残像が左右から寄って重なり、スパークする。

## WAVE 8 クリア後 — ドッキング〜VOID（ver.4.5）

WAVE 8 クリア後、操作なしの演出シーケンスに入る。

1. **X / BB 接近** … 自機と BB が左右から寄る
2. **ドッキング** … 結合完了（assembled ship）
3. **地球接近** … 結合機が地球へ
4. **THE VOID** … 出現 → 活動開始 → 重力場展開
5. **To Be Continued…** → END

※ VOID の発狂・自爆フェーズ画像は素材として同梱。演出への本組みは後続。

## 敗北ヒント（ランダム）

防衛失敗時に1つ表示される例:

1. アイテムは地上に転がってから取りにいけ。
2. 地上に転がるのはアイテムだけ。敵弾は転がらない。
3. アイテムはしばらくすると消える。急いで取れ。
4. 連射・三連は、上を横切る敵を倒したときだけ落ちる。
5. 速射・三連の効果は 約6〜7秒。タイミングを逃すな。
6. シールドは耐久制。薄く点滅したらあと少し。
7. 知恵の実で都市が育つ。一度発展したら戻らない。
8. スモッグが多いと画面が霞む。撃って晴れ。
